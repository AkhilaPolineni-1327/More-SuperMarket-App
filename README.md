# More SuperMarket App

A mobile UI/UX design project for a supermarket shopping application created using Figma.

## Project Overview

More SuperMarket App is designed to provide users with a simple and convenient way to browse products, explore categories, and manage their supermarket shopping.

## Features

* Simple and clean mobile interface
* Product categories
* Product browsing
* Search functionality
* Shopping cart
* User-friendly navigation
* Modern mobile UI design

## Tools Used

* Figma
* UI/UX Design
* Wireframing
* Prototyping
